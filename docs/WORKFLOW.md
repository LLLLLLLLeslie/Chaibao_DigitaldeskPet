# 制作记录

## 已确认的形象

用户确认采用最终修订版：适中的头身比、略圆脸颊、自然口鼻、直立三角耳、黑色短毛、金色眼睛。避免夸大的英短大圆头。主形象为 `assets/source/chaibao.png`。

## 流程

1. 以同一主形象为依据，分别生成九个动作条。
2. 使用原版脚本提取完整连通姿势，并检查帧数、背景与连贯性。
3. 统一各动作比例与站立基线，保留跳跃的真实竖直位移。
4. 生成四个基本视线方向，再依次生成两行共十六个视线方向。
5. 组装 1536×2288 的 v2 图集，清理背景边缘一次，运行结构、方向和质量验证。
6. 从最终图集输出动画预览，验证通过后上传并选用。
