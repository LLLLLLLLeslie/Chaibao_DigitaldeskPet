# 使用柴宝桌宠

在本机双击桌面的「柴宝桌宠」即可启动。柴宝坐着时，鼠标轻扫或点击他，会随机舔爪、用爪子洗脸或举爪。休息时碰他会坐起来。按住左键可以拖动，右键可以关闭。使用其他程序不会重置计时。五分钟未碰他会揣手趴下，十分钟会蜷睡。

## 换一台 Windows 电脑

下载并解压整个项目。安装带 Tk 的 Python 3，在项目目录运行：

```powershell
python -m pip install Pillow
pythonw chaibao.pyw
```

ChatGPT 内置宠物使用同一坐姿和新版侧面步态。计时休息由独立的 Windows 版提供。若同时显示两只，可在 ChatGPT 输入框选择 `/pet` 命令收起内置宠物。
