# 在 ChatGPT 桌面显示柴宝

本机已经完成安装，已在 Windows 桌面右下角确认柴宝出现。可以用“显示虚拟宠物”打开，或用 Windows + Alt + P 切换显示。

## 在另一台电脑安装

1. 用拥有柴宝的账号打开 ChatGPT 桌面版，并连接 Pets。
2. 在聊天中发送“请给我柴宝的桌面安装链接，宠物 ID 是 pet_6af44200f51881918adc16d028ef9653”。
3. 点击生成的安装链接，用 ChatGPT 打开。如果出现选择提示，选“柴宝”，然后打开“显示虚拟宠物”。

安装链接使用有时效的图集地址。链接过期时可按第 2 步重新获取。

[ChatGPT Pets 使用说明](https://learn.chatgpt.com/docs/pets)
